SubBuild Studio for macOS
=========================

Install: drag "SubBuild Studio" onto the Applications folder.

First launch: the app is not signed with an Apple Developer ID yet, so macOS asks you to
confirm it once:
  1. Open SubBuild Studio from Applications. macOS says it could not verify the app - click "Done".
  2. Open System Settings > Privacy & Security, scroll down, and click "Open Anyway"
     next to SubBuild Studio. Confirm with your password.
  After that it opens normally.
  (On macOS 14 and older: right-click the app > Open > Open.)

Updating: download the new version and drag it onto Applications again (replace).
Your projects, settings and API keys are kept in
~/Library/Application Support/SubBuild Studio.

Website: https://subbuildstudio.com
Source code: https://github.com/talevi83/SubBuildStudio


SubBuild Studio ל-macOS
========================

התקנה: גוררים את "SubBuild Studio" לתיקיית Applications (יישומים).

הפעלה ראשונה: האפליקציה עוד לא חתומה במזהה מפתח של Apple, ולכן macOS מבקש אישור פעם אחת:
  1. פותחים את SubBuild Studio מתיקיית היישומים. macOS אומר שלא הצליח לאמת את האפליקציה - לוחצים "סיום".
  2. פותחים הגדרות המערכת > פרטיות ואבטחה, גוללים למטה ולוחצים "לפתוח בכל זאת"
     ליד SubBuild Studio, ומאשרים עם הסיסמה.
  מכאן והלאה היא נפתחת כרגיל.
  (ב-macOS 14 ומטה: קליק ימני על האפליקציה > פתיחה > פתיחה.)

עדכון: מורידים את הגרסה החדשה וגוררים שוב ל-Applications (החלפה).
הפרויקטים, ההגדרות ומפתחות ה-API נשמרים ב-
~/Library/Application Support/SubBuild Studio
